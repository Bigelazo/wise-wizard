# Idea futura: estilos de citación intercambiables

El estudiante podría elegir otro estilo de citación además de APA 7, como IEEE, Chicago o MLA. Hoy todas las Citas se muestran en APA 7. Como una Cita se guarda como datos y la app la formatea al mostrarla (ADR-0021), cada estilo nuevo sería solo otro formateador, sin tocar prompts, herramientas ni Citas guardadas.
