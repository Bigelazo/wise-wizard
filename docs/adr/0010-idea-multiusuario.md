# Idea futura: multiusuario

Pasar a varios usuarios requiere tres cambios: agregar registro y aislar los datos por `ownerId` (ADR-0001); migrar el motor de IA a API key, porque la suscripción no puede usarse en nombre de otros (ADR-0003); y revisar la exposición pública de la app (ADR-0002).
