# Idea futura: búsqueda académica y web como respaldo

Cuando las Fuentes del Cuaderno no cubran una Consulta, la IA bajaría por una jerarquía: primero la búsqueda académica en OpenAlex o Semantic Scholar, que tienen API abierta (Google Scholar no tiene API y prohíbe el acceso automatizado), y después la web general. La respuesta diría explícitamente "esto no está en tus Fuentes", y las Citas externas se mostrarían distintas de las de la Biblioteca, también en formato APA. Hoy la regla vigente es la del ADR-0006.
