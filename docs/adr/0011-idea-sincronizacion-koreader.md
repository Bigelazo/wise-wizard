# Idea futura: sincronizar el Progreso de lectura con KOReader

El estudiante lee en un Kindle con KOReader, y existe un repositorio que sincroniza ese avance con el PC. La idea encaja sin cambiar el modelo: KOReader informa una página y el Progreso de lectura es una Página impresa. Hay que considerar que KOReader cuenta páginas del archivo PDF, así que se necesita la misma conversión de página del PDF a Página impresa que usan las Citas.
